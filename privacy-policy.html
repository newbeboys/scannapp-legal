Kebijakan Privasi

Cara ScannApp mengumpulkan, menggunakan, dan melindungi data Anda.

Berlaku sejak 13 Agustus 2026 Versi 1.0 Bahasa Indonesia

Kebijakan Privasi ini menjelaskan bagaimana Ali Sodikin ("kami", "Kami"), selaku pengembang perorangan, mengumpulkan, menggunakan, menyimpan, dan melindungi data Anda saat menggunakan aplikasi ScannApp ("Aplikasi").

Dengan menggunakan Aplikasi, Anda menyetujui praktik yang dijelaskan dalam Kebijakan Privasi ini.

01Data yang Kami Kumpulkan

Data akun. Saat Anda mendaftar, kami mengumpulkan alamat email, kata sandi (disimpan terenkripsi — kami tidak pernah melihat kata sandi asli Anda), dan nama tampilan opsional.

Data dokumen. Hasil pindai dokumen Anda disimpan secara lokal di perangkat Anda secara default. Kami tidak mengakses atau melihat isi dokumen Anda kecuali Anda aktifkan fitur "Backup ke Cloud" — jika diaktifkan, file disimpan di penyimpanan cloud (Cloudflare R2) yang kami kelola, dan kami menyimpan metadata (judul, jumlah halaman, ukuran file, tanggal) untuk sinkronisasi. Kami tidak membaca atau membagikan isi dokumen Anda untuk tujuan komersial apa pun.

Akses kamera. Aplikasi meminta izin kamera untuk fungsi pemindaian. Pemrosesan gambar (deteksi tepi, koreksi perspektif) dilakukan sepenuhnya di perangkat Anda menggunakan Google ML Kit — gambar tidak dikirim ke server kami hanya untuk proses pemindaian.

Data teknis. Jenis perangkat, versi sistem operasi, log error/crash, dan status tier akun (Basic/Pro).

Data iklan (tier Basic). Ditampilkan lewat Google AdMob, yang dapat mengumpulkan advertising ID perangkat Anda sesuai Kebijakan Privasi Google. Dapat diatur ulang lewat pengaturan Android Anda.

Data pembayaran. Diproses sepenuhnya oleh Google Play Billing dan RevenueCat. Kami tidak pernah menerima atau menyimpan informasi kartu Anda.

03Pihak Ketiga yang Memproses Data Anda

  • Supabase — autentikasi & database (server Asia Pacific/Tokyo)
  • Cloudflare R2 — penyimpanan backup dokumen (opsional)
  • Google AdMob — penayangan iklan (tier Basic)
  • RevenueCat & Google Play Billing — pemrosesan langganan Pro

Masing-masing memiliki kebijakan privasi sendiri yang mengatur pemrosesan data mereka.

04Penyimpanan & Keamanan Data

Dokumen Anda disimpan lokal di perangkat secara default — pendekatan "local-first" ini sengaja dipilih agar Anda memiliki kendali penuh atas file Anda. Backup cloud bersifat opsional, bukan otomatis.
  • Akses database dibatasi lewat kebijakan Row Level Security — setiap pengguna hanya dapat mengakses datanya sendiri.
  • Kredensial penyimpanan cloud tidak pernah dikirim ke aplikasi Anda; transfer file memakai URL bertanda tangan yang kedaluwarsa dalam 10 menit.

05Berapa Lama Kami Menyimpan Data Anda

Data akun disimpan selama akun Anda aktif. Jika Anda menghapus akun, data profil dan metadata dokumen dihapus dari sistem kami dalam waktu 30 hari, termasuk file backup di cloud. Dokumen yang disimpan lokal di perangkat Anda tetap ada sampai Anda menghapusnya sendiri — di luar kendali kami karena tidak pernah menyentuh server kami.

06Hak Anda

Sesuai UU Pelindungan Data Pribadi (UU No. 27 Tahun 2022), Anda berhak untuk:

  • Mengakses data pribadi yang kami simpan tentang Anda
  • Meminta koreksi data yang tidak akurat
  • Meminta penghapusan akun dan data terkait
  • Menarik persetujuan pemrosesan data Anda kapan saja

Untuk menggunakan hak-hak ini, hubungi kami di supportscannapp@gmail.com.

07Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak secara sadar mengumpulkan data pribadi dari anak-anak di bawah usia tersebut. Jika Anda orang tua/wali dan mengetahui anak Anda telah memberikan data pribadi kepada kami, hubungi kami untuk penghapusan.

08Perubahan Kebijakan Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan signifikan akan diberitahukan melalui Aplikasi atau email terdaftar Anda.
